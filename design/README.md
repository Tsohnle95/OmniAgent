# Session panel directions

Open `index.html` in a browser to review 100 session-panel concepts. The gallery can be searched, filtered by family, previewed in both product themes, and used to shortlist up to four directions.

Every concept is constrained to the current file-panel language:

- the product system font stack;
- cream, beige, brown, and sage tokens from `_foundation.scss`;
- title weights between 400 and 525;
- existing file-tree icons, indentation, section labels, hover washes, counts, and slim active indicators;
- transparent lists instead of stacked cards, prominent borders, shadows, or display typography.

The concepts are organized as ten information-architecture families with ten typography and density treatments in each family. The specification line above every panel identifies the title size, title weight, row height, and active-state treatment.

Shortlist IDs are stable from `001` through `100`. Use an ID when choosing a direction for production implementation.
