# Active agent tasks

This directory is temporary working memory for multi-phase PROJECT work and
large BATCH work.

- Start from `_TEMPLATE.md`.
- Name active files descriptively, e.g. `runtime-resume-refactor.md`.
- Keep them compact and factual.
- Commit them while work is active when cross-session recovery matters.
- Update phase status and commit ids after verified checkpoints.
- Do not use task files as permanent architecture documentation.
- On completion, move durable truths to their canonical docs, move remaining
  future work to issues/backlog, then delete the task file.

PATCH work should never create a task file. FEATURE work should normally keep a
short plan in context unless it will span multiple sessions/agents/commits.
